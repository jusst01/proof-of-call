Don’t trust callers. Verify them.

Alpha callers delete their misses, edit their calls, and screenshot only the wins. Proof of Call ends that: a caller registers a call on-chain, before the move — the block timestamp can’t be forged. An oracle fetches the entry price from DexScreener (the caller never types it) and scores the call at 15m / 1h / 6h / 24h. Wins and losses stay on the record, forever.

🔍 How it works — and how to verify everything

  1. Register. The caller signs register_call(chain, token_ref, direction). The contract stores the signer and the block timestamp. That pair is the proof the call existed, then.
  2. Entry price. Set only by the oracle, fetched from DexScreener at registration time and stored verbatim — compare it against the public source tick-for-tick.
  3. Scoring. At fixed horizons — 15m / 1h / 6h / 24h, no discretion — the oracle records the exit price (verbatim) and the return in basis points from the caller’s perspective. One outcome per horizon, append-only.
  4. Receipt. Every call mints one receipt NFT to the caller at registration: portable proof of when the call was made.
  5. Recompute it yourself. Every number on this page is a view call against one public contract. Take any stored entry/exit price pair and the direction — the return is arithmetic anyone can redo.
